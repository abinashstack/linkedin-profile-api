LinkedIn Profile Lookup

Reverse-engineered against LinkedIn's own internal API. API docs

By default this uses the LinkedIn session already configured on the server. If you paste a cookie below instead, it's sent directly to this server over HTTPS for this lookup and then discarded — never written to a file, logged, or cached. Even so, an li_at cookie grants full access to whatever LinkedIn account it belongs to, exactly like a password — only paste one you're comfortable sharing with this server.

Looked up one at a time with a short delay between each, not all at once. A large batch may be rejected — split it into smaller requests if so.
